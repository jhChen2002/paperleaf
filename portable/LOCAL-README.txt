纸间 Paperleaf 1.0.0 — Windows 本地版

1. 先将整个 ZIP 解压到一个普通文件夹，例如 D:\Paperleaf。不要直接在压缩软件里运行。
2. 进入解压后的 portable 文件夹，双击 Start-Paperleaf.cmd。软件会在默认浏览器中打开 http://127.0.0.1:43127。
3. 导入 PDF 或文件夹，即可分类、切换阅读状态、添加摘录和检索笔记。
4. 退出时先等待左下角显示“已保存到本机”，然后双击 Stop-Paperleaf.cmd。

此版本不用安装 Node.js，不用注册账号。支持 Windows 10/11 x64。
浏览器只是界面；论文和笔记保存在解压目录下的 data 文件夹，不会上传到网站。
本地版与云端版使用独立的文献库，不会自动相互同步。

备份：运行 Stop-Paperleaf.cmd 停止后台后，复制整个 data 文件夹，包含 library.sqlite 和 files。只关闭浏览器不会停止后台。
更新或迁移：先停止并备份，再把 data 完整复制到新解压的 portable 文件夹中，然后启动。
分享：向同门发送原始 ZIP。不要把自己用过的 data 文件夹发出去。
应用内 JSON 导出只含文献信息和笔记，不含 PDF；完整备份请复制 data。

导入按 5 MiB 分块传输，显示每篇文件的进度，短暂失败会自动重试。
点击“暂停上传”后保留当前网页，再用“继续未完成的文件”恢复；已完成的分块不用重传。
刷新或关闭网页后需要重新选择文件，不支持跨网页会话续传。请等到显示导入完成再关闭页面。

双击文献即可阅读，用鼠标滚轮从上往下连续浏览；输入页码并点击“跳转”可以直接定位。
阅读器按需加载内容，只绘制阅读位置附近的页面，并在当前网页中临时缓存最近使用的 PDF。
选中文字后点击“摘录并记录”，自动关联论文与页码。扫描 PDF 可用“添加笔记”手动记录。
全库搜索覆盖书目信息、标签、摘录与笔记；PDF 全文搜索在阅读器内使用。
点击笔记的来源页码可返回原文。高亮和笔记保存在应用中，不会写入原 PDF。
暂不包含 OCR、DOI 自动补全或 Word 引用插件。单篇文件不超过 40 MiB（41,943,040 字节，界面显示为 40 MB）。

多设备同步请使用自己部署的云端站点，在不同设备以同一账号登录同一网址。
各电脑的本地版与云端版相互独立；复制 data 是迁移或备份，不是自动同步。

如果启动失败，请查看 data/server-error.log，或确认 43127 端口没有被其他程序占用。
本地服务仅绑定 127.0.0.1；请勿自行改为公网监听。
